# Pedal Companions

An interactive companion to the **Chase Bliss Lost + Found** manual — the
enclosure drawn and made clickable, the twelve modes browsable two at a time,
and every section linked to the page the manual prints.

Live at **https://fuzzbyte.github.io/pedal-companions/**.

## A companion, not the manual

The page points back at Chase Bliss's own manual throughout, by the page number
the manual prints, and every one of those links opens their PDF at that page.
Where the page states something the manual does not — an inferred knob position,
a suggested starting point — it says so in place.

No manual is reproduced here in full, and there is no PDF in this repository.
But the mode and knob descriptions are largely Chase Bliss's own words, quoted
from the manual rather than written here. [NOTICE](NOTICE) sets out exactly
which parts those are.
