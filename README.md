# Pedal Companions

Interactive companions to guitar pedal manuals — the enclosure drawn and made
clickable, with the maker's own documentation linked beside it.

Live at **https://fuzzbyte.github.io/pedal-companions/**.

| Pedal | The companion |
|---|---|
| [Chase Bliss Lost + Found](chase-bliss-lost-and-found-interactive.html) | The twelve modes browsable two at a time, with the bidirectional Modify knob that does nothing at noon |
| [Strymon Volante](strymon-volante-interactive.html) | The four playback heads, and every repeat drawn on a timeline as you move them |
| [Fulltone OCD-Germanium](fulltone-ocd-germanium-interactive.html) | Three knobs and a switch, plus what Michael Fuller says the pedal responds to that isn't on the enclosure |

## Companions, not manuals

Each page points back at the maker's own manual throughout — by the page number
the manual prints, where the maker's PDF is the same document we read — and
every one of those links opens their copy, not ours. Where a page states
something the manual does not, it says so in place.

No manual is reproduced here in full, and there is no PDF in this repository.
But the descriptions of what each control does are largely the makers' own
words, quoted rather than written here. [NOTICE](NOTICE) sets out exactly which
parts those are, per pedal, and names the product photographs on the homepage.
