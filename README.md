# Pedal Companions

Interactive companions to guitar pedal manuals — the enclosure drawn and made
clickable, the controls answerable, and every section linked to the page the
manual prints.

Live at **https://fuzzbyte.github.io/pedal-companions/**.

Three companions so far:

- **Chase Bliss Lost + Found** — the twelve modes browsable two at a time.
- **Strymon Volante** — the tape deck running, with the four heads audible.
- **Fulltone OCD-Germanium** — the panel annotated control by control.

The index lists the rest of the shelf too. Those cards are marked *building*
and link straight to the manufacturer's own manual until a companion for them
lands.

## A companion, not the manual

Each page points back at its maker's own manual throughout, by the page number
the manual prints — as a link into the maker's own PDF where that PDF opens in
a browser, and as the printed page number alone where it does not. Where a page
states something the manual does not — an inferred knob position,
a suggested starting point, a gloss on a term the manual never defines — it
says so in place.

No manual is reproduced here in full, and there is no PDF in this repository.
But the control and mode descriptions are largely the makers' own words, quoted
from their manuals rather than written here. [NOTICE](NOTICE) sets out exactly
which parts those are, maker by maker, and covers the product photography on
the index as well.

## Building

The pages are generated from a private working repository and copied here.
Edits should be made there, not to the files in this repo — the next build
overwrites them.
