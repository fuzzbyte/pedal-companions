What the eight knobs do on each machine

Four of the eight knobs do the same job on all twelve machines: VALUE, MIX and TONE, and TYPE, which always picks the machine. The other four change with the machine. DECAY covers a different range on nearly every one, and on Magneto, Nonlinear and Reflections it sets something other than a decay time. PRE-DELAY becomes a Feedback control on Magneto and Nonlinear. MOD is a different modulator on each machine. PARAM 1 and PARAM 2 point at a different pool of parameters every time you turn TYPE. Click a name to load that machine into the pedal above.

Assigning PARAM 1 and PARAM 2

“The PARAM 1 & PARAM 2 knobs allow you quick access to any desired menu parameter of the currently active reverb machine.” Manual pg. 4.

Assigning a parameter

The manual's four steps, on pg. 4:

  1. “Navigate to the desired parameter to be assigned.”
  2. “Press and hold the value encoder.”
  3. “While holding the value encoder. Turn either the PARAM 1 or PARAM 2 knob to assign a parameter.”
  4. “Turn the newly assigned PARAM knob to adjust your reverb machine parameter.”

To reach a parameter in the first place, from pg. 6: while displaying BANK, NAME or TIME, “push the VALUE encoder to enter PARAMS menu”, “turn the VALUE encoder to select the desired PARAMETER”, then “push the VALUE encoder and turn to edit the selected PARAMETER”.

What the manual does not print

The manual describes both PARAM knobs as assignable and gives the procedure above. It does not say which parameter each knob arrives assigned to on a factory preset. So the selectors above start on the first two parameters in the manual's own listing for the machine, and you can point them at any parameter in the list.

The one assignment the manual does name is on Cloud: “DIFUSN on the Cloud machine can be assigned to one of the parameter knobs to allow for easier control over the reverb diffusion.”

The twelve machines

In the order the TYPE encoder steps through them, which is also the order the manual prints them and the order the LEDs run clockwise round the encoder. Every quotation on a card — the description, the parameter definitions and the tips — is copied from that machine's own page in the manual, linked at the foot of the card.

Banks, presets and saving

Quotations here are from manual pg. 6, except where another page is named.

Banks and presets

“BigSky has 100 banks with A, B, and C presets in each bank. Banks are numbered 00 to 99 on the display.” That is 300 presets. From pg. 2: “Press A & B to select a lower bank. Press B & C to select a higher bank.”

“BigSky ships from the factory with the first 100 presets (00A-33A) duplicated from 33B-66B, and again from 66C-99C.”

The A, B and C LEDs, from pg. 2: “Green if active. Amber if the preset has been edited. Off if bypassed.”

Saving

To the current location: “hold the TYPE encoder”, then “push the TYPE encoder to save your settings”.

To a new location: “hold the TYPE encoder”, “turn the VALUE encoder to select the bank to save to”, then “push the TYPE encoder or the A, B, or C footswitch to save your settings”.

“To cancel an in-progress save press the VALUE encoder.”

Restoring the factory presets

“POWER UP BigSky while holding A & C. Keep holding for 5 seconds after BigSky has powered up. REINIT will be displayed and all factory patches will automatically be restored”.

“CAUTION: This procedure will erase any custom patches saved in your BigSky and restore them to factory”.

What the display is showing

The diagram on pg. 4 has the TYPE encoder pushed to toggle the display between BANK, NAME and TIME. Which one is showing changes what the VALUE encoder does — from pg. 2, “Turn for fine adjustment of Decay time when time is displayed. Scrolls through presets when bank or name is displayed.”

“The displayed Decay time is the RT60 value, which is the time it takes for the reverberated signal to decay to -60dB (1/1000th) of its initial value.” Pg. 4.

The rear panel

Quotations are from manual pg. 3, the EXP jack from pg. 5 and the cab filter from pg. 22.

Power

“Never plug into voltage higher than 9V DC. Requires at least 300mA of available current. 9V DC center negative polarity.”

Inputs and outputs

“High impedance inputs. Use LEFT input for mono.” And for the outputs: “Use LEFT output for mono.”

Cab filter switch

“If outputting to a full-range PA system, recording interface, or headphones, place BigSky last in your effects chain and set the CAB FILTER switch to the ON position. This will engage our sophisticated speaker response curve. Your dirt pedals will sound amp-like, and your clean guitar will have a present yet rounded response even without an amp.”

“If outputting to a guitar amp, set the CAB FILTER switch to the OFF position.”

EXP — expression pedal

“Connect a standard TRS expression pedal for continuous control over any knob. To select the knob(s) controlled by the expression pedal, use the EP SET parameter in each preset. All knobs can be controlled simultaneously.”

EXP — switches

“Connect a Strymon MiniSwitch for remote control of Pre-Delay (or Decay time with the Magneto and Nonlinear machines). Use a standard TRS cable to connect the external switch. Set the EXP MD global setting to TAP to use external tap.”

“Connect a Strymon MultiSwitch for external tap, bank, or preset selection. Set the EXP MD global setting to either TAP, BANK, or PRESET.”

MIDI

“Full featured MIDI input and output supporting CCs, Program changes, etc.”

From pg. 23: “Because MIDI Program Change messages have a maximum number of 128 (0-127), the presets are grouped into 3 MIDI Patch Banks” — bank 0 is 00A–42B, bank 1 is 42C–85A, bank 2 is 85B–99C.
